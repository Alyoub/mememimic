# Audio sources

## Remote `realSound` behavior

- `realSound: true` uses the bundled meme clips in `EchoBloom/Sounds/`. These are supplied project assets and may require separate clearance before public distribution.
- `realSound: false` uses the original prompts in `SoundLibrary.originalPacks`. They are synthesized at runtime from sine waves, harmonics, filtered noise, envelopes, and simple formant filters. No recording, sample, melody, or third-party audio file is used.

## Copyright-safe prompt source

All fallback prompt designs and synthesis code were created specifically for Meme Mimic in this repository on 2026-10-26. They have no external source or attribution requirement and may be used with the app without a third-party audio license.

Interface cues (`tick`, `go`, `reveal`, and `pop`) are also generated by the same in-app synthesizer.
